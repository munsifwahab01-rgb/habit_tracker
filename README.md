# Smart Habit Tracker

Smart Habit Tracker is a simple web application developed using HTML, CSS, Bootstrap, JavaScript, PHP, and MySQL.

## Features

- User Registration
- User Login
- User Logout
- Password Hashing
- Add Daily Habits
- Mark Habits as Completed
- Delete Habits
- Filter Habits
- Contact Form
- Responsive Bootstrap Design
- JavaScript Interactivity
- CSS Animation

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- MySQL

## Database Name

habit_tracker

## Tables

- users
- habits
- messages

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into:

   C:\xampp\htdocs\

4. Open phpMyAdmin.
5. Create a database named:

   habit_tracker

6. Import database.sql.
7. Open the project using:

   http://localhost/habit_tracker/
